# Security Policy

## Reporting
This is an educational repository. If you find a security issue in the example code, please open an issue or contact via LinkedIn.

## Observability & Security
This episode covers security observability in depth — see src/security_and_audit/README.md:
- PII detection and redaction in logs
- Audit logging
- Prompt injection detection
- Compliance logging and data residency

Never log secrets, API keys, or unredacted PII. All examples redact by default.
