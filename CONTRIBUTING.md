# Contributing

This is Episode 11 of the AI Engineering Roadmap 2026 series. Contributions welcome!

## Ways to contribute
- Fix bugs in examples
- Add real implementations to code stubs
- Improve the deep-dive READMEs
- Add observability tool integrations
- Share production observability patterns

## Process
1. Fork and branch
2. Make your change
3. Run `make test`
4. Open a PR with a clear description

## Standards
- Structured logging everywhere (no bare prints in real code)
- Low-cardinality metric labels
- Every new section gets a deep-dive README
