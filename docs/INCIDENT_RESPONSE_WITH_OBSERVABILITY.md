# Incident Response with Observability

## Roles
- Incident Commander (coordinates)
- Investigator (uses observability to find cause)
- Communicator (status updates)
- Scribe (documents timeline)

## Observability's Role
- Shared source of truth (everyone works from same data)
- Timeline reconstruction (from traces/metrics)
- Cause localization (metric → trace → log)
- Postmortem evidence

## The Loop
Every incident should reveal what observability was MISSING. Add that instrumentation. Each incident makes your observability better.
