# Glossary

**Cardinality** — number of unique label combinations for a metric. High cardinality breaks metrics systems.
**Counter** — a metric that only increases (total requests).
**Drift** — statistical change in inputs/outputs over time that degrades performance.
**Error budget** — allowed failure under an SLO (100% - SLO).
**Gauge** — a metric that goes up and down (active connections).
**Golden signals** — latency, traffic, errors, saturation.
**Histogram** — a metric capturing distributions (for percentiles).
**KL divergence** — measure of difference between two distributions.
**Log** — a timestamped record of a discrete event.
**Metric** — a numeric measurement aggregated over time.
**Observability** — understanding internal state from external outputs.
**OpenTelemetry (OTel)** — the open standard for observability instrumentation.
**PSI** — Population Stability Index, a drift measure.
**RED method** — Rate, Errors, Duration (for services).
**Request ID** — correlation ID linking all telemetry for one request.
**Sampling** — keeping a subset of telemetry to control cost.
**SLI** — Service Level Indicator (what you measure).
**SLO** — Service Level Objective (your target).
**SLA** — Service Level Agreement (contractual promise).
**Span** — a single unit of work in a trace.
**TTFT** — Time To First Token (perceived LLM latency).
**Trace** — the full tree of spans for one request.
**Trajectory** — the full sequence of steps an agent took.
**USE method** — Utilization, Saturation, Errors (for resources).
