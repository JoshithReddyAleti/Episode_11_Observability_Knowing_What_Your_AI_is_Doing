# Enterprise Observability

What changes at scale. See src/enterprise_patterns/README.md.

## Key Additions
- Multi-tenant isolation in all observability data
- SLO/SLI/SLA hierarchy with error budgets
- Formal on-call and incident command
- Observability as code (version-controlled)
- Observability governance (standards, cost, access, ownership)
- Compliance-grade audit logging with retention policies
- Data residency for observability data
